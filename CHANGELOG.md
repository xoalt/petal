# Changelog

## 0.1.0-beta.1 — 2026-10-20

First public beta of Petal, an unofficial, independently written Linux reimplementation of Tangerine for macOS.

- Radial conversion wheel with expanding petals and keyboard modes for formats, tools, and file actions.
- Empty leaf feedback, center file selection, and optional floating drop target.
- Separate settings, system tray menu, and file shelf.
- First-launch application and appearance choices, with neutral conversion-program lists and capability checks.
- Local conversions and editing tools, with collision-safe outputs and cancellation support.
- User-selected Petal logo, Wayland layer support, documented installation, and verified source archives.

This is a beta, not a stable release. Format support depends on installed engines and codecs. See the known limitations and release verification notes in docs/.
