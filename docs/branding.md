# Petal branding

The name Petal was chosen by the user. The shipped six-petal orange/coral logo is the exact transparent PNG selected and supplied by the user on 2026-10-20, preserved byte-for-byte as assets/petal-logo.png. Only assets/petal.png is resized to 256×256 for application and tray use. No recoloring, cleanup, or redrawing was applied to the supplied logo.

Earlier design exploration used the built-in OpenAI image-generation tool. The following prompts document that exploration; they do not claim that the final user-supplied file is an unmodified output from those tool calls.

Initial prompt: create one original, text-free Petal app mark: six broad curling petals rotating clockwise around a small transparent center, crisp vector-like geometry, warm orange/coral palette, recognizable at tray sizes, transparent background, no citrus fruit, tile, border, texture, lettering, or watermark.

Refinement prompt: preserve the six silhouettes, positions, clockwise arrangement, center opening, and framing; remove detached marks and edge noise; simplify toward alternating #ff650f and #f04432 fills, transparent gaps/outside, and a crisp 24px silhouette. The model retains subtle tonal variation; the shipped file is the actual generated output, not claimed to be editable vector artwork.

Earlier generation used the built-in image tool; no CLI/API-key fallback was used. The final asset selection came directly from the user. Assets and third-party notices are in assets/NOTICE.txt. The original Tangerine project is credited separately at https://tangerineformac.com/.
