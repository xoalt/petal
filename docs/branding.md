# Petal branding

The name Petal was chosen by the user. The six-petal clockwise rosette was created specifically for this app using the built-in OpenAI image-generation tool, not copied from Tangerine's artwork. The generated logo retains transparency; the application icon is a resized export. The full-resolution image is assets/petal-logo.png and the app/tray asset is assets/petal.png.

Initial prompt: create one original, text-free Petal app mark: six broad curling petals rotating clockwise around a small transparent center, crisp vector-like geometry, warm orange/coral palette, recognizable at tray sizes, transparent background, no citrus fruit, tile, border, texture, lettering, or watermark.

Refinement prompt: preserve the six silhouettes, positions, clockwise arrangement, center opening, and framing; remove detached marks and edge noise; simplify toward alternating #ff650f and #f04432 fills, transparent gaps/outside, and a crisp 24px silhouette. The model retains subtle tonal variation; the shipped file is the actual generated output, not claimed to be editable vector artwork.

Generation used the built-in image tool; no CLI/API-key fallback was used. Assets and third-party notices are in assets/NOTICE.txt. The original Tangerine project is credited separately at https://tangerineformac.com/.
